# CSS Layer

The CSS layer is the foundation of Civaria. It provides every component as a set of plain CSS classes — no JavaScript required. This makes it usable in any framework, server-rendered HTML, or static site.

## Installation

```bash
pnpm add @civaria/tokens @civaria/css
```

Import both packages in your root stylesheet or layout:

```css
/* In your global CSS */
@import "@civaria/tokens/tokens.css";
@import "@civaria/css";
```

Or in a Next.js / React root layout:

```tsx
// app/layout.tsx
import "@civaria/tokens/tokens.css";
import "@civaria/css";
```

## Cascade Layers

The Civaria CSS is wrapped in a named `@layer` so it sits at a predictable specificity level. Your own styles will override Civaria without needing `!important`.

```css
/* Civaria ships wrapped like this */
@layer civaria.reset, civaria.tokens, civaria.base, civaria.components;

/* Your overrides automatically win */
.civ-button {
  border-radius: 9999px; /* pill-shaped buttons */
}
```

The layer order from lowest to highest priority:

1. `civaria.reset` — minimal CSS reset
2. `civaria.tokens` — CSS custom property definitions
3. `civaria.base` — base element styles (body, headings)
4. `civaria.components` — component classes

## Naming Convention

Civaria uses BEM (Block, Element, Modifier) with a `civ-` prefix:

```
civ-{block}               Block
civ-{block}__{element}    Element
civ-{block}--{modifier}   Modifier
```

Examples:

```html
<!-- Block -->
<div class="civ-card">

  <!-- Element -->
  <div class="civ-card__header">Card Title</div>
  <div class="civ-card__content">Body</div>
  <div class="civ-card__footer">Footer</div>
</div>

<!-- Block + Modifier -->
<button class="civ-button civ-button--solid">Primary</button>
<button class="civ-button civ-button--outline">Secondary</button>
<button class="civ-button civ-button--ghost">Tertiary</button>
```

## Using Without JavaScript

Every component in the CSS layer renders correctly in static HTML. There is no hydration step, no runtime bundle, and no framework dependency.

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <link rel="stylesheet" href="/tokens.css" />
  <link rel="stylesheet" href="/civaria.css" />
</head>
<body>
  <!-- Fully functional with zero JavaScript -->
  <button class="civ-button civ-button--solid">Click me</button>

  <div class="civ-card">
    <div class="civ-card__header">
      <h2>Hello World</h2>
      <span class="civ-badge civ-badge--success">Live</span>
    </div>
    <div class="civ-card__content">
      <p>This page has no JavaScript.</p>
      <input class="civ-input" placeholder="Still works" />
    </div>
  </div>
</body>
</html>
```

## Component Reference

### Button

```html
<button class="civ-button civ-button--solid">Solid</button>
<button class="civ-button civ-button--outline">Outline</button>
<button class="civ-button civ-button--ghost">Ghost</button>
<button class="civ-button civ-button--soft">Soft</button>

<!-- Size modifiers -->
<button class="civ-button civ-button--solid civ-button--sm">Small</button>
<button class="civ-button civ-button--solid civ-button--lg">Large</button>

<!-- Disabled state -->
<button class="civ-button civ-button--solid" disabled>Disabled</button>
```

### Input

```html
<input class="civ-input" type="text" placeholder="Default" />
<input class="civ-input" type="text" value="Invalid value" data-invalid="true" />
<textarea class="civ-input" rows="4" placeholder="Multiline"></textarea>
```

### Badge

```html
<span class="civ-badge civ-badge--solid">Default</span>
<span class="civ-badge civ-badge--outline">Outline</span>
<span class="civ-badge civ-badge--success">Success</span>
<span class="civ-badge civ-badge--warning">Warning</span>
<span class="civ-badge civ-badge--destructive">Error</span>
```

### Avatar

```html
<!-- With image -->
<span class="civ-avatar">
  <img src="/avatar.jpg" alt="Jane Doe" class="civ-avatar__image" />
</span>

<!-- Fallback initials -->
<span class="civ-avatar">
  <span class="civ-avatar__fallback">JD</span>
</span>

<!-- Size modifiers -->
<span class="civ-avatar civ-avatar--sm">...</span>
<span class="civ-avatar civ-avatar--lg">...</span>
```

### Card

```html
<div class="civ-card">
  <div class="civ-card__header">
    <h3>Title</h3>
    <p class="civ-card__description">Optional subtitle</p>
  </div>
  <div class="civ-card__content">
    <!-- Main content here -->
  </div>
  <div class="civ-card__footer">
    <button class="civ-button civ-button--solid">Action</button>
  </div>
</div>
```

## Customizing Tokens

Override any CSS custom property after importing Civaria to theme components globally:

```css
@import "@civaria/tokens/tokens.css";
@import "@civaria/css";

/* Custom theme */
:root {
  --civ-color-primary: oklch(55% 0.20 160); /* green primary */
  --civ-radius-md: 0.75rem;                 /* rounder corners */
}
```
