## Quick start

```tsx
// your-app/layout.tsx
import "@civaria/tokens/tokens.css";
import "@civaria/css";

export default function RootLayout({ children }) {
  return <html><body>{children}</body></html>;
}
```

```tsx
// your-app/page.tsx
import { Button } from "civaria";

export default function Page() {
  return <Button>Hello Civaria</Button>;
}
```

Your tokens default to system light/dark via `prefers-color-scheme`. Add a `dark` class or `data-theme="dark"` on `<html>` to opt into manual dark mode.
