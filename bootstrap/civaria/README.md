# Civaria

**WCAG-first. Governance-ready.**

This is the bootstrap release that reserves the unscoped `civaria` package name while the design-system repository completes its full product and package rename.

The production entrypoint will replace this bootstrap package in a subsequent release. The modular packages will live under the controlled `@civaria/*` namespace.

While the repository still contains the legacy `@weiui/*` package namespace, the normal Changesets publish path remains disabled so the old namespace cannot be published accidentally.
